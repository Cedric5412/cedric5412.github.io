# Cedric Pizina

A simple black-and-white personal website for GitHub Pages. One HTML file, inline CSS, and no JavaScript or dependencies.

## Preview

Open `index.html` in your browser. It works offline.

## Personalize

Edit `index.html` directly. Replace the bracketed text with your biography, experience, education, and selected work. Add your real contact links inside `contact-links`. Remove any sections you do not need.

When the content is ready, remove the draft label and the `noindex, nofollow` robots meta tag. Update the page description if needed.

## GitHub Pages

This package is ready to upload. It has not been pushed to GitHub or published.

1. Create a repository named `YOUR-USERNAME.github.io`, substituting your actual GitHub username in lowercase. For GitHub Free, use a public repository.
2. Put `index.html`, `.nojekyll`, and this README at the repository root on `main`. Upload the extracted files, not the ZIP or its containing folder.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, then **main** and **/(root)**. Save.
5. GitHub will show the published address, normally `https://YOUR-USERNAME.github.io/`.

You can also use a differently named repository as a project site. All navigation uses in-page anchors, so this site also works beneath a repository subpath.

`.nojekyll` is an empty file that disables Jekyll processing. No custom Actions workflow, build command, or package installation is needed.
